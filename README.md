# flashami-money-form

旅行イベント向けの支出入力・集計Discord Botです。

現在は仕様策定とNode.jsプロジェクトの初期化のみ完了しています。Bot本体、Google Sheets連携、Google Drive連携は未実装です。

## MVP

- Discordのボタンから支出登録モーダルを開く
- 個人立替と共通予算からの支出を区別する
- 支払者、対象者、用途、金額、レシートをDiscord上で入力する
- レシートをGoogle Driveへ保存する
- 支出データをGoogle Sheetsへ保存する
- 個人立替のみを精算対象にして、誰が誰へいくら支払うかを集計する
- 共通予算の使用額と残額を集計する

## 対象外

- Web管理画面
- 複数イベントを操作する管理UI
- 決済や送金そのもの
- 会計ソフト連携

実装は仕様確認後に開始します。
